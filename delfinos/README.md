# DelfínOS

Firmware del Flipper Zero en español, basado en Momentum-Firmware, con herramientas curadas y probadas.

- `index.html`: página web del proyecto (instalador web por WebSerial, emulador del menú en español, catálogo de herramientas, pipeline de calidad, panel de administración de demo y aviso de uso responsable).
- Página publicada: https://claude.ai/artifact/2U94sQVLWLjwNuKUw1WSpm
